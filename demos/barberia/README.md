# Navaja Barber Club — demo de Ecnexo Digital

Web de demostración para el portafolio de Ecnexo Digital. El negocio, la carta y los precios son de ejemplo.

- Abrir: `index.html`
- Reglas de diseño: `DESIGN.md` (manda sobre `design-system/`, que es la salida de UI UX Pro Max)
- WhatsApp: cambia `CONFIG.whatsapp` en `js/main.js`
- Fuentes alojadas en `assets/fonts`, logos en `assets/logo`, imagen para compartir en `assets/img`
- Para convertirla en la web de un cliente real: cambia nombre, textos, precios, horario, número y quita la franja `.demo` y `noindex`.
